# Week8 Mission

## 작업 내용
- 3주차 RecyclerView 기반 상품 리스트를 Compose LazyColumn으로 마이그레이션했습니다.
- LazyColumn의 items()를 사용하여 상품 리스트를 표시했습니다.
- ProductItem Composable을 작성하여 기존 item layout과 ViewHolder 역할을 대체했습니다.
- 각 상품에 id 기반 key를 지정하여 상태 안정성을 확보했습니다.
- 구매하기 화면에서 하트 클릭 시 위시리스트에 상품이 추가/삭제되도록 구현했습니다.
- 피드백을 반영하여 navigation, component, data, screen 단위로 파일을 분리했습니다.
